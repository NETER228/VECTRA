# Vectra

Статический сайт на HTML, CSS и JavaScript. Посетители могут играть как гости без записи результатов или создать аккаунт по логину и паролю. Для аккаунтов Supabase Auth использует внутренний email-идентификатор, полученный из логина; пользователь почту не указывает. Восстановление пароля не предусмотрено.

## Запуск

Раздайте папку через HTTP, например `python -m http.server 8000`, и откройте `http://localhost:8000`. Для гостевого режима анонимный вход Supabase не требуется.

Для **новой** базы выполните в SQL Editor по порядку:

1. `supabase/schema.sql` (удаляет старые таблицы Vectra и их данные);
2. `supabase/migration_app_state.sql`;
3. `supabase/migration_server_answers.sql`;
4. `supabase/migration_server_scoring.sql`.
5. `supabase/migration_guest_readonly.sql`;
6. `supabase/migration_username_accounts.sql`.

В Supabase Auth отключите подтверждение почты (Authentication → Providers → Email → Confirm email), иначе регистрация с внутренним адресом не сможет завершить вход. Пользователь сам отвечает за сохранность логина и пароля: сброс пароля через почту или телефон отсутствует.

Для **существующей** базы не запускайте `schema.sql` повторно: он удаляет статистику. Сначала сверьте её таблицы, функции и список миграций с этими файлами, сделайте резервную копию и применяйте только недостающие изменения. На 30 октября 2026 года в рабочем проекте Supabase уже установлены серверные таблицы ответов, серверный подсчёт и режим гостевого чтения рейтинга. При изменении `data/questions.json` или `data/objects.json` запустите `python tools/build_truth_sql.py` и примените обновлённый `migration_server_answers.sql`.

## Классы для второй части задания

`GameSession` объявлен в `js/core.js` и используется в `js/compare.js` и `js/weight.js`. Конструктор создаёт состояние партии: текущий раунд, сумму очков, историю ответов и список заданий. Метод `addRound(entry)` добавляет результат раунда и обновляет счёт. Каждая новая партия — отдельный экземпляр класса. Остальной код организован функциями и модулями; CSS-классы не являются классами JavaScript.

## Ограничения защиты

Гостевые результаты не отправляются на сервер и не меняют рейтинг. Вошедшие пользователи сохраняют результаты через серверные RPC; таблицы остаются закрытыми от прямой записи благодаря RLS. Капча в этой версии — необязательная задача с линией, а не защита от ботов. Publishable-ключ Supabase в `js/config.js` публичный; безопасность данных зависит от RLS и прав RPC.
