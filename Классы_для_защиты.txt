VECTRA — КЛАССЫ И ООП В JAVASCRIPT
Памятка для защиты второй части проекта

1. Что такое ООП

ООП — объектно-ориентированное программирование. Это способ строить программу
из объектов, которые хранят свои данные и предоставляют действия для работы
с ними.

Класс — описание того, как устроены объекты одного вида.
Объект (экземпляр класса) — конкретная созданная сущность с собственными данными.
Свойство — данные объекта. Метод — функция, объявленная внутри класса.

Пример из жизни: класс «Игровая партия» задаёт, какие данные нужны каждой игре.
Объект — конкретная партия Compare’It, сыгранная сейчас.

2. Где класс находится в проекте

Класс GameSession объявлен в js/core.js и добавлен в общий объект Vectra.
Compare’It и «Угадай вес» создают экземпляры этого класса:

js/compare.js:
  new Vectra.GameSession(pickPairs(), 'pairs')

js/weight.js:
  new Vectra.GameSession(pickObjs(), 'objs')

3. Код класса

class GameSession {
  constructor(items = [], kind = 'pairs') {
    this.round = 0;
    this.score = 0;
    this.log = [];
    this[kind] = items;
  }

  addRound(entry) {
    this.log.push(entry);
    this.score += entry.pts;
    return this.score;
  }
}

4. Как это работает

constructor — специальный метод. JavaScript запускает его при создании объекта
через new. В конструктор передаются задания партии и тип списка заданий.

this — ссылка на конкретный экземпляр. Поэтому у каждой партии свои round,
score и log. Данные одной новой партии не смешиваются с данными другой.

round — номер текущего раунда. В начале он равен 0; игровой код увеличивает его
после перехода к следующему раунду.

score — сумма очков партии.
log — массив результатов сыгранных раундов.
items — список заданий. В Compare’It это пары объектов, в игре про вес — объекты.
kind — строка 'pairs' или 'objs'. Запись this[kind] задаёт свойство по имени,
которое пришло в kind: получается this.pairs или this.objs.

addRound(entry) — метод для добавления результата раунда. Он записывает entry
в журнал, прибавляет entry.pts к общему счёту и возвращает новый счёт.

5. Небольшой пример

const game = new Vectra.GameSession(['Земля и Юпитер'], 'pairs');
game.addRound({ pts: 80, k: 'earth>jupiter' });

После вызова game.score будет 80, а в game.log будет один результат.
Если создать другую партию через new Vectra.GameSession(...), её счёт начнётся
с нуля, а журнал будет пустым.

6. Какой принцип ООП виден в проекте

Инкапсуляция — связанные данные и операции над ними находятся вместе в
GameSession: счёт и журнал обновляются методом addRound.
При этом свойства открытые: код может обратиться к game.score напрямую.
Поэтому это базовая инкапсуляция, а не строгая защита данных через private.

Наследование — создание нового класса на основе другого с помощью extends.
В проекте оно не используется: двум режимам хватает одного общего класса.

Полиморфизм — один и тот же интерфейс может иметь разное поведение у разных
типов объектов. В GameSession полиморфизм явно не реализован.
На защите правильно сказать, что используется класс и базовая инкапсуляция,
а наследование и полиморфизм в этой версии не применяются.

7. Зачем класс нужен именно здесь

Оба режима проводят партию из нескольких раундов и должны хранить похожее
состояние: номер раунда, сумму очков, задания и историю ответов. GameSession
собирает это состояние и общий метод добавления результата в одном месте.
Игровые режимы используют один шаблон, передавая каждый свой список заданий.

8. Что ответить преподавателю

— Что такое класс?
  Описание, по которому создаются объекты с общими свойствами и методами.

— Что такое объект?
  Конкретный экземпляр класса, созданный в программе.

— Что делает new?
  Создаёт экземпляр и вызывает его constructor.

— Что означает this?
  Ссылку на текущий экземпляр; через неё код читает и меняет его данные.

— Где в Vectra используется класс?
  GameSession объявлен в js/core.js, экземпляры создаются в js/compare.js
  и js/weight.js.

— Есть ли в проекте наследование?
  Нет. Для текущих игровых режимов достаточно общего класса GameSession.

— CSS-класс и класс JavaScript — одно и то же?
  Нет. CSS-класс, например class="card", выбирает оформление HTML-элемента.
  JavaScript-класс объявляется через class и описывает объекты и их поведение.

— Где хранится статистика игрока?
  GameSession хранит данные текущей партии в памяти страницы. Для вошедшего
  пользователя итоговые результаты отдельно отправляются в Supabase; класс
  игровой сессии сам по себе не является базой данных.

9. Короткий рассказ для защиты

«В проекте я использовал класс GameSession, который находится в js/core.js.
Он описывает состояние одной игровой партии: текущий раунд, сумму очков,
список заданий и журнал результатов. При старте режима через new создаётся
отдельный экземпляр. Compare’It и игра про вес используют этот же класс,
но передают разные задания. Метод addRound записывает ответ и прибавляет
очки к общему счёту. Это пример класса и базовой инкапсуляции; наследование
в проекте не понадобилось».

Важно: в проекте есть один класс JavaScript — GameSession. Остальные части
в основном организованы функциями и модулями. CSS-классы в HTML — это стили,
они не считаются классами ООП.
